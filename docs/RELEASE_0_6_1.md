# RoGoal v0.6.1 - Novo visual e diagnóstico do Studio

## PT-BR

- A tela inicial ganhou um campo para descrever seu projeto e copiar o pedido para seu chat de IA. A barra lateral, o editor, o Explorer, a busca e os painéis usam a mesma linguagem visual.
- As transições usam GSAP incluído no aplicativo e respeitam a preferência por movimento reduzido do Windows.
- O painel Project context indica quando o plugin conectado não suporta a exportação. Ele oferece acesso à release e à pasta Plugins. Feche o Studio, substitua o arquivo RoGoal.rbxmx, reabra e refaça o pareamento.

## English

- The home screen, sidebar navigation, Explorer, search, editor chrome, and dialogs share a chat-inspired design, with a project prompt composer on the home screen.
- GSAP is bundled locally and respects reduced-motion preferences.
- Project context reports Studio plugin compatibility and provides links to the release and local Plugins folder. Close Studio, replace RoGoal.rbxmx, restart Studio, and pair again.
