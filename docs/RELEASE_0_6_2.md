# RoGoal v0.6.2 - Importação direta e interface simplificada

## PT-BR

- Use **Paste AI response** na tela inicial, cole a resposta ou abra o arquivo, confira os destinos e clique em **Apply to Studio**.
- O importador aceita JSON puro, um bloco JSON acompanhado de texto e os pacotes TXT existentes.
- O plugin Studio tem uma tela de conexão com status, versão e acesso às configurações. Atualize o aplicativo e o arquivo RoGoal.rbxmx.

## English

- Open **Paste AI response** from Home, paste or open the file, review the destinations, and select **Apply to Studio**.
- Import accepts raw JSON, one JSON code block surrounded by prose, and existing TXT bundles.
- The Studio plugin has a single connection screen with status, version, and settings. Update both the app and RoGoal.rbxmx.
