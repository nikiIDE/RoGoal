# RoGoal v0.6.3 - Estrutura do jogo e Quick Apply separados

## PT-BR

- **Game structure** organiza pastas e scripts vazios. Copie o prompt de estrutura, cole o JSON retornado, confira os destinos e clique em **Create in Studio**.
- **Quick Apply** continua disponível para criar ou modificar scripts com código.
- Foram padronizados ícones, cantos, tipografia, rolagem e transições. Atualize o aplicativo Windows e o plugin RoGoal.rbxmx e refaça o pareamento.

## English

- **Game structure** creates folders and empty scripts from an organization plan.
- **Quick Apply** remains available for creating and updating scripts with source code.
- Icons, control corners, typography, scrollbars and transitions share a consistent style. Update both the desktop app and RoGoal.rbxmx and pair again.
