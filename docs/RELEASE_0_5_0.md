# RoGoal v0.5.0 - Nova interface para Studio e Windows

## PT-BR

- O plugin agora se chama RoGoal e usa um widget acoplável do Roblox Studio com abas **Pair** e **Session**.
- O aplicativo Windows ganhou o tema **Studio**, tela de pareamento atualizada e controles que se adaptam à largura da janela.
- O pareamento local, a sincronização de Luau, o Explorer, o Quick Apply e a recuperação de rascunhos continuam disponíveis. O app usa o diretório de dados da versão anterior.
- Instale `RoGoal-Setup-0.5.0.exe` e use `RoGoal.rbxmx` no Roblox Studio.

## English

- The RoGoal Studio plugin uses a dockable widget with **Pair** and **Session** tabs.
- The Windows app includes a new **Studio** theme, a redesigned pairing screen, and controls that adapt to the window width.
- Local pairing, Luau synchronization, Explorer, Quick Apply, and recovery are available. The app reuses the previous release's data directory.
- Install `RoGoal-Setup-0.5.0.exe` and use `RoGoal.rbxmx` in Roblox Studio.
